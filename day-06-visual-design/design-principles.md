# Design Principles


## Typography

**Font:** one family, set once on `body` and inherited everywhere.
`font-family: system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif;`

**Type scale:** ratio 1.25, base 1rem. Each step is the previous one × 1.25.

| Role | Size | Used for |
|---|---|---|
| Body | 1rem (16px) | paragraphs, nav links, list |
| h3 | 1.25rem (20px) | card title |
| h2 | 1.562rem (~25px) | section headings |
| h1 | 2rem (32px) | hero heading (rounded from 1.953rem) |
| Next step up | 2.441rem (~39px) | available for a bigger hero |

**Line-height**
- Body text: `1.5`
- Large headings: `1.1`, because big text needs less relative leading.
- Always unitless, never a fixed px value.

**Line length:** `max-width: 60ch` on paragraphs and headings. The hero h1 uses `30ch`.

**Units:** `rem` for font sizes and spacing, so everything respects the user's browser setting. No px on font sizes.

## Spacing

**Spacing scale:** only multiples of 0.5rem (8px).

| Value | Pixels | Used for |
|---|---|---|
| 0.5rem | 8px | small gaps inside a component |
| 1rem | 16px | heading-to-text gap, section side padding |
| 2rem | 32px | nav gap, card padding, larger separations |

**Rule:** related things sit close, unrelated things sit far apart.
- Heading → its own text: small (0.5–1rem)
- Section → section: large (2rem or more)

## Color and hierarchy

- Hierarchy comes from size, weight and color together, not size alone.
- Body text should meet a 4.5:1 contrast ratio against its background.
- Palette in this project: beige background, black text, black footer with white text.

## Mistakes to catch on any page

1. **Scale built by adding, not multiplying** (1, 2, 3, 4rem instead of a ratio).
2. **Fixed pixel heights** on boxes that hold text.
3. **Cramped line-height** on paragraphs (below about 1.4).
4. **Inverted gaps:** the space around a heading's own text is bigger than the space between sections.
5. **Selector commas:** `.card h3, p, a` styles every `p` and `a` on the page. Each selector in a list needs its own scope.
6. **Margin collapsing:** adjacent vertical margins merge into the larger one, so the smaller margin does nothing.
7. **Off-grid values** like 1.2rem or 2.2rem.

## Known gaps in this version (to improve next time)

- Buttons are still plain links.
- Sections have no vertical padding.
- Hierarchy relies mostly on size, with little weight or color difference.
- Content is left-aligned with no centered wrapper.
