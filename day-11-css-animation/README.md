It was supposed to be day-12 task that I need to complete but I took yesterday and today to complete this one task, which is of animation. The task is not up to the par but atleast I know how to use @keyframes and also the shorthand form of animation property, which is:

animation: name duration timing-function delay iteration-count direction fill-mode;

1. name: name of the animation you gave
2. duration: the time up to which the animation will work
3. timing-function: acceleration and speed curve of the animation(ease-in, ease, ease-out.....)
4. delay: after how many seconds will the animation start
5. iteration-count: how many times do you want to run an animation(most of the time we use 'infinite')
6. direction:  determines whether the animation plays forward, backward, or alternates back and forth.
7. fill-mode: defines whether an element keeps the animation's styles before it starts (during the delay) and after it finishes.
